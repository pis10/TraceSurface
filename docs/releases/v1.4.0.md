## AI Review：按站点分析重放结果

扫描完成后，可以手动选择站点，或选择筛选结果中的全部站点，让模型分析已有的 **2xx + JSON** 重放结果。疑似接口集中显示在 AI Review 中，附带判断依据、验证建议和原始报文，便于人工复核。

- 每个站点独立分析；尚未完成扫描或没有符合条件接口的站点会跳过。
- 模型目录由 Pydantic AI 提供，支持服务商与模型搜索、思考强度选择和连接测试。
- 支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Gemini generateContent 四种自定义接入格式。
- 任务进度、失败原因与重试入口集中展示；关闭网页后任务继续运行。
- 更新中英文 README、使用指南与报告截图。

AI 为可选功能，扫描与重放无需模型服务。API Key 保存在本机；只有主动发起分析时，扫描报文才会发送至所配置的服务。

## 升级说明

**v1.4.0 不兼容旧版数据与 AI 配置，不提供迁移。** 请保留旧数据目录，通过 `TRACESURFACE_HOME` 指定一个新目录，然后重新扫描和配置模型。程序不会自动转换或删除旧数据。

- macOS / Linux：`export TRACESURFACE_HOME="$HOME/.tracesurface-v1.4"`
- Windows PowerShell：`$env:TRACESURFACE_HOME = "$env:USERPROFILE\.tracesurface-v1.4"`

扫描和报告服务需要使用同一数据目录。重新扫描同一站点会替换其旧扫描及关联的 AI 结果。

## English

**AI Review** adds manual, site-based analysis of existing 2xx JSON replay results. Select individual sites or all filtered sites, then review suspected endpoints in one list with evidence, verification suggestions, and original traffic.

Model setup uses the Pydantic AI catalog, reasoning effort settings, and a connection test. Custom endpoints support OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, and Gemini generateContent. Scanning and replay remain independent of AI.

**Breaking change:** older data and AI settings are incompatible. No migration is provided. Keep the old directory, point `TRACESURFACE_HOME` to a fresh directory, then rescan and configure your model. Existing data is never automatically converted or deleted.

Download the archive for Windows x86_64, macOS Apple Silicon, or Linux x86_64. Checksums are included in `SHA256SUMS`.
